Acerca del proyecto

Nébula Arcade es un proyecto académico centrado en videojuegos, desarrollado para practicar HTML5 semántico, CSS externo avanzado y transformación de datos XML con XSLT. Todo el catálogo se genera del lado del cliente: no hay backend ni base de datos.

Arquitectura técnica

Componentes técnicos del sitio y su función
Componente Archivo Función
Estructura index.html, about.html, catalog.html, contact.html Contenido semántico de las cuatro páginas del sitio
Estilos css/styles.css Variables CSS, Grid/Flexbox, responsive y animaciones
Datos data/datos.xml Ocho registros de videojuegos con sus atributos
Validación data/datos.dtd Define y valida la estructura obligatoria del XML
Transformación data/catalogo.xsl Convierte el XML en tarjetas HTML de catálogo
Interactividad js/catalog.js, js/contacto.js, js/main.js Carga del XSLT, filtros por género y validación de formulario
